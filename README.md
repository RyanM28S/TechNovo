# 📌 Visão Geral

O **TechInvestment** é uma plataforma web criada para auxiliar usuários no gerenciamento de investimentos, acompanhamento patrimonial e organização financeira.

O sistema apresenta dashboards modernos, metas mensais, carteira de ativos e recursos para acompanhamento financeiro em tempo real.

---

# ✨ Principais Funcionalidades

✅ Sistema de Login e Cadastro  
✅ Dashboard Financeiro  
✅ Controle Patrimonial  
✅ Metas Mensais  
✅ Carteira de Investimentos  
✅ Perfil do Usuário  
✅ Área da Equipe  
✅ Interface Responsiva e Moderna

Criar uma solução digital moderna para investidores iniciantes e intermediários, oferecendo controle financeiro simples, visual atrativo e acesso rápido às informações da carteira.
